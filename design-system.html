01. Design System

Typography, colour, spacing and components for every screen, mobile and desktop. Pick a text style by its role (screen title, sheet title, section heading…), never by eye. Chipotle has two type tiers: condensed uppercase display type for anything that labels, and Nunito for anything you read. Desktop only enlarges the four title tiers; reading sizes stay put.

Rules for new screens

9 rules
DoChoose by role, not by sizeAsk "is this a top-bar title, a sheet title, or a group label?" and use that style. If none fits, reuse the closest one. Don't add a size.
DoDisplay labels, body readsAnything that names or labels (titles, section heads, item names, buttons, field labels) is display tier. Anything a customer reads as a sentence, or a number they compare (prices, totals), is Nunito.
DoOne title per screenEach screen gets at most one t-title-1. Sheets use t-title-2. Top bars, builder sections and product names use t-title-3.
DoLet the tokens handle desktopNever write html.is-desktop .x{font-size:…}. Title tiers already grow on html.is-desktop. If an element needs a different role on desktop, swap the class.
DoInputs are 16pxEvery <input>, <select> and <textarea> uses t-input. Today .text-input, the search pill and the phone field are 14px, which makes iOS Safari zoom on focus.
DoOne button sizeEvery full-width action (Continue, Next, Add to bag, Pay, Track order) is t-button. Today they're split between 20px (.btn-primary, .btn-add) and 16px (.btn-checkout-pay, .btn-success-primary).
Don'tFlip hierarchy with weightA group heading must outrank its options: builder section titles (18) over ingredient names (16) over the calorie line (14/400). Don't make a price heavier than the item it prices.
Don'tGo below 12pxThe smallest text is t-tag at 12px. .kb-tag (10px) and .byo-section-title .num (11px) move up; the VISA card tag is a logo mark, so swap it for the real card-brand SVG.
Don'tTrade Gothic Condensed has a 16px floorIt's only drawn at real weight down to 16px (t-headline). Any role below that — t-label (14px), t-tag (12px) — uses Nunito Bold instead, uppercase + tracked the same way, so it still reads as a label or tag.

TokenValueRule
  • Two side margins. Content uses --space-page-x (20px). Top bars and the two-column menu grid use --space-bar-x (16px). Today the builder and quick-add body are 20px and the top bars are 16px, so this matches the prototype.
  • One divider. Sections are split by a full-bleed 8px --cream-deep band. Today the builder uses a 12px border and checkout an 8px band with 8px margins; both become the 8px band with 28px above the next heading.
  • No margins on rows. Space comes from the parent: side padding from the body, gap between rows, and the heading's bottom margin above the first row. Today .variant-row and .pay-row set their own margin-bottom (12px and 10px).
  • Option rows: see Option card below for the card's inner spacing.

  • Don't resize or restyle the column, status bar or browser bar. They're device chrome, and they don't use the type tokens.
  • Screen content uses 20px side padding, a sticky top bar (.checkout-top-bar: back arrow, centred t-title-3 title) and, when there's a main action, a sticky footer with one t-button.
  • Leave --space-footer (100px) at the bottom of scrolling content so the footer doesn't cover it.
  • Desktop (?view=desktop) sets html.is-desktop today, which grows the title tiers; no screen has a desktop layout yet. When one lands it drops the column and the two bars and fills the window.

Using it in the prototype

2 steps
  1. Add <link rel="stylesheet" href="design-system.css"> in the prototype's <head>, before its own <style>.
  2. For new screens, use the classes (class="t-title-3") or the variables inside your own selectors:
/* New screen: Rewards */
.rewards-title   { font-family:var(--font-display); text-transform:uppercase; letter-spacing:var(--ls-display);
                   font-size:var(--fs-title-1); line-height:var(--lh-title-1); font-weight:var(--fw-title-1); }
.reward-name     { font-family:var(--font-display); text-transform:uppercase; letter-spacing:var(--ls-display);
                   font-size:var(--fs-headline); line-height:var(--lh-headline); font-weight:var(--fw-headline); }
.reward-desc     { font-family:var(--font-body); font-size:var(--fs-body); line-height:var(--lh-body); font-weight:var(--fw-regular); }
.reward-points   { font-family:var(--font-body); font-size:var(--fs-callout); line-height:var(--lh-callout); font-weight:var(--fw-callout); color:var(--red); }

/* …or in markup */
<h2 class="t-title-1">Your rewards</h2>
<p class="t-body">Earn 10 points for every $1 spent.</p>
